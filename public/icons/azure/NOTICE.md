# Azure architecture icons

These files are unmodified copies from Microsoft's Azure Public Service Icons (V21),
downloaded from https://learn.microsoft.com/en-us/azure/architecture/icons/.

Microsoft's terms, quoted from that page:

> Microsoft permits the use of these icons in architectural diagrams, training materials, or documentation. You can copy, distribute, and display the icons only for the permitted use unless granted explicit permission by Microsoft. Microsoft reserves all other rights.

Use them only in architecture diagrams and explainers about Azure systems. Don't
change them, and don't use them as a show's branding, wordmark or thumbnail art.
